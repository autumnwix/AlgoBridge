Role definitions
| User            | Expected usage                                           | Access                                                             |
| --------------- | -------------------------------------------------------- | ------------------------------------------------------------------ |
| Guest           | Explore and complete guided exercises without an account | Published exercises, feedback, hints, and temporary practice only  |
| Student/Learner | Practice regularly and track progress                    | Guest features plus personal saved sessions, resume, and dashboard |
| Admin           | Maintain the educational content                         | Draft and published exercise management through protected tools    |

Learners are assumed to know introductory programming and basic algorithm knowledge.
