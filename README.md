# AlgoBridge

AlgoBridge is an interactive platform that helps CS students practice algorithm problem-solving through step-by-step reasoning exercises.

This repository is for SP1 at Assumption University, Thailand, developed by Autumn and Aon.

This README is mainly used to track progress and link important project documents.
