# AlgoBridge

**AlgoBridge** is a cross-platform educational application designed to help computer science students strengthen algorithm reasoning through guided exercises and structured feedback.

## Project Information

- **Project Type:** Undergraduate Senior Project I
- **Development Team:** Autumn & Aon
- **Project Status:** Planning and requirements definition
- **Repository Visibility:** Private

## Project Objectives

1. Develop a guided learning experience for selected algorithm topics.
2. Provide structured exercises that encourage step-by-step reasoning.
3. Evaluate supported answers through deterministic rules.
4. Deliver actionable explanations and predefined hints.
5. Support learning activities across Web and Mobile applications.

## Project Scope

The initial MVP focuses on a curated exercise library, guided problem-solving, answer evaluation, structured feedback, and basic progress tracking.

Advanced AI features, arbitrary code execution, competitive programming functionality, and social features are excluded from the initial MVP.

See [Project Scope](docs/scope.md) for detailed features and exclusions.

## Project Management

Development tasks, priorities, and milestones are managed through GitHub Issues and GitHub Projects.

## Development Status

The project is currently in its initial planning phase. The implementation architecture and technical stack will be finalized after the MVP requirements are reviewed.
